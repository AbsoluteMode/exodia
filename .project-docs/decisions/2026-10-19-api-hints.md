# API hints

## Behavior

Settings -> API & Models shows API hints as its fourth internal tab, after
API keys, Models and Costs. It contains four provider cards in two columns.
Existing monochrome brand marks, prominent allowances, a separate cadence and
concise conditions make the offers scannable. Claude Max retains a visible
**Paid plan** label. The user replaced the former quiet bottom link/native sheet
with this tab on 2026-10-20; the offer content and verification date are unchanged.

Each card links to its official offer. **Add API key** switches to API keys and
opens the existing add-key form; it does not save or select anything by itself.
Native buttons and links retain keyboard focus and provider-specific
accessibility labels. The embedded version has no Done button; navigation uses
the shared four tabs. The standalone sheet retains its existing footer controls.
The shared surface and period behavior are recorded in
[feature costs](2026-10-20-feature-costs.md).

The card is editorial guidance, not a live balance or eligibility check. Opening
it makes no requests and changes no keys or routes. Provider links open only
when clicked. Keyboard and accessibility behavior use native SwiftUI controls.

Exodia itself is free; provider usage can be covered within a free allowance or
by an existing paid subscription. Do not promise permanently unlimited free
operation. Local model execution is not a suggested route: it was removed.

## Offer evidence

Checked on **2026-10-19** against these official sources:

- [Deepgram pricing](https://deepgram.com/pricing): new-account $200 starter
  credit, then usage-based billing; no card needed to start. Treat this as a
  one-time starting allowance, not a monthly credit.
- [ElevenLabs developer API](https://join.elevenlabs.io/api/developer-api):
  Free includes 10,000 credits per month and API access.
  [API pricing](https://elevenlabs.io/pricing/api) lists distinct Scribe realtime
  and batch allowances. Do not convert credits to a universal audio duration.
- [OpenRouter's cost guide](https://openrouter.ai/blog/tutorials/how-to-get-the-lowest-cost-llm-inference-on-openrouter/):
  free models allow 50 requests/day and 20/minute without purchasing credits.
  Agent tool cycles may require several requests. Use an explicit `:free` model
  suited to the feature; do not automatically choose or replace a route.
- [Claude monthly API credits](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-and-team-plans):
  Max 5x supplies $100/month, Max 20x $200/month. Claim after seven days on an
  eligible subscription by linking a Console organization in Claude billing.
  Use its Anthropic key for the Agent feature. Credits expire each billing
  cycle, are shared within that organization, and do not pay for requests sent
  through Exodia's OpenRouter account. Free and Pro plans are ineligible.

The verification date and a reminder to check current eligibility, limits and
billing settings remain visible in the sheet footer. When changing an offer,
recheck its official source and update the date and this record together.
